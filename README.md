# Hermes-officer                                                   
## 项目简介
面向职场个人用户打造 Multi-Agent AI 助理，支持自动报告撰写、数据洞察分析等核心能力；基于 Plan-Execute 双层 Agent 编排架构完成任务自动拆解、执行闭环与失败自动Replan 重规划；搭载 RAG 个人知识库，依托 MCP 协议实现工具热插拔，完整支撑业务全链路自动化运行。
## 项目亮点
- 基于 Plan-Execute 层级编排多Agent架构实现任务拆解与执行闭环，支持执行失败自动 Replan 重规划，同时兼容轻量化纯 React 直答模式，兼顾复杂推理与简单问答响应效率。
- 设计三层记忆架构，通过短期对话上下文、内置记忆文件与插件化外部长期记忆分层协作，结合上下文压缩与异步沉淀实现从实时交互到跨会话持久化的全链路记忆能力。
- 设计异步双路沉淀记忆机制，通过后台子Agent结合线程级工具白名单隔离实现子Agent仅操作内部记忆/Skill工具，使得后台同步沉淀用户画像与可复用skill等。
- 设计技能库自愈机制，先以确定性时间规则零成本过滤过期技能，再以独立 LLM 子代理做语义级整合——将 200+ 碎片技能收敛为 30+ 类级 Umbrella 技能，提升检索匹配精度。
- 自研三级渐进式上下文压缩机制，占用 60% 淘汰过期工具中间态，83.5% 启用常驻摘要子 Agent 做增量总结，异常则降级全量摘要，资源超限熔断并提示新建会话。
- 依托 Resilience4j 搭建全链路可靠性体系，基于会话 - 对话 - 工具分级超时、分类指数退避重试、滑动窗口熔断实现故障隔离；通过双向精细化限流，入向按 IP / 账号控流自保，出向管控 LLM 并发、Token 与第三方调用频次；
